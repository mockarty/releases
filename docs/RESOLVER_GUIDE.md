# Mock Resolver

[Русская версия](#mock-resolver-на-русском) · [Community Server](../README.md)

Add a resolver when you want dedicated capacity for mock traffic. Start the admin node first. Obtain a resolver integration token and configure the connection using the [resolver setup instructions](https://mockarty.ru/docs/deployment-guide#mockarty-resolver).

Use a resolver binary or image listed with the selected [Mockarty release](https://github.com/mockarty/releases/releases). Use the [native protocol guide](https://mockarty.ru/docs/native-protocol-mocks) to choose the correct listener for each protocol.

## Mock Resolver на русском

[Community Server](../README.md#mockarty-community-на-русском)

Подключите резолвер, чтобы выделить ресурсы для трафика моков. Сначала запустите админ-ноду. Выпустите токен интеграции для резолвера и настройте подключение по [руководству по развёртыванию](https://mockarty.ru/docs/deployment-guide?lang=ru#mockarty-resolver).

Используйте бинарник или образ резолвера, указанный в выбранном [релизе Mockarty](https://github.com/mockarty/releases/releases). Адрес обработчика каждого протокола см. в [руководстве по нативным мокам](https://mockarty.ru/docs/native-protocol-mocks?lang=ru).
