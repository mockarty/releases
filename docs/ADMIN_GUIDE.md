# Mockarty admin node

[Русская версия](#админ-нода-mockarty) · [Community Server](../README.md)

The admin node serves the web UI, REST API, native mocks and the coordinator for optional test runners and resolvers. Start a [Community Server](../README.md#start-community-server-with-docker) and create a local admin account. Continue with the [deployment guide](https://mockarty.ru/docs/deployment-guide) for a server others will access.

Use the [native protocol guide](https://mockarty.ru/docs/native-protocol-mocks) to configure listeners. Use the [administration guide](https://mockarty.ru/docs/admin-setup) to manage workspace membership and permissions.

## Админ-нода Mockarty

[Community Server](../README.md#mockarty-community-на-русском)

Админ-нода обслуживает веб-интерфейс, REST API и нативные моки, а также координирует подключённые раннеры тестов и резолверы. Запустите [Community Server](../README.md#запуск-community-server-в-docker) и создайте локального администратора. Если к серверу будут обращаться другие пользователи, следуйте [руководству по развёртыванию](https://mockarty.ru/docs/deployment-guide?lang=ru).

Настройте обработчики по [руководству по нативным протоколам](https://mockarty.ru/docs/native-protocol-mocks?lang=ru). Состав пространств и права настраиваются по [руководству администратора](https://mockarty.ru/docs/admin-setup?lang=ru).
