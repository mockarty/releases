# Mockarty test and coding runners

[Русская версия](#раннеры-тестов-и-разработки-mockarty) · [Community Server](../README.md)

| Task | Component and setup |
|---|---|
| Execute distributed tests | Choose `mockarty-runner` from the [Mockarty release assets](https://github.com/mockarty/releases/releases). Start the admin node, then follow the [test runner setup instructions](https://mockarty.ru/docs/deployment-guide#mockarty-runner). |
| Connect a coding worker | Choose a published `mockarty-coder-runner` from [Downloads](https://mockarty.ru/downloads#coding-runner). Configure the workspace API token and admin public key described in the [coding runner trust guide](https://mockarty.ru/docs/ai-components#trust-setup). |

Verify a downloaded binary against `checksums.txt` from the same release. The server checks who may connect a runner and start work. Community can register a coding runner. Autonomous missions require Enterprise.

## Раннеры тестов и разработки Mockarty

[Community Server](../README.md#mockarty-community-на-русском)

| Задача | Компонент и запуск |
|---|---|
| Выполнять распределённые тесты | Выберите `mockarty-runner` среди [файлов релиза Mockarty](https://github.com/mockarty/releases/releases). Запустите админ-ноду и следуйте [инструкции для раннера тестов](https://mockarty.ru/docs/deployment-guide?lang=ru#mockarty-runner). |
| Подключить раннер разработки | Выберите опубликованный `mockarty-coder-runner` на [странице загрузок](https://mockarty.ru/downloads?lang=ru#coding-runner). Настройте токен API пространства и публичный ключ административного узла по [руководству по доверию](https://mockarty.ru/docs/ai-components?lang=ru#настройка-доверия). |

Сверьте скачанный бинарник с `checksums.txt` того же релиза. Сервер проверяет права на подключение раннера и запуск задач. Community поддерживает регистрацию раннера разработки. Для автономных миссий требуется Enterprise.
