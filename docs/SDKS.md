# Mockarty SDKs

[Русская версия](#sdk-на-русском) · [Community Server](../README.md)

Install a version from the package registry for your language. The source repository for each SDK has examples, release history and its licence. Consult the licence shipped with your selected SDK version.

| SDK | Package | Repository |
|---|---|---|
| Go | `github.com/mockarty/go-sdk` | [mockarty/go-sdk](https://github.com/mockarty/go-sdk) |
| Python | [`mockarty` on PyPI](https://pypi.org/project/mockarty/) | [mockarty/py-sdk](https://github.com/mockarty/py-sdk) |
| Java | [`ru.mockarty:mockarty-java` on Maven Central](https://central.sonatype.com/artifact/ru.mockarty/mockarty-java) | [mockarty/java-sdk](https://github.com/mockarty/java-sdk) |

Use the [SDK quick start](https://mockarty.ru/docs/sdk-quick-start) to connect to an installed server and exercise a mock from your tests. Use a token for the workspace your tests target. The connected server checks the workspace role and module access.

## SDK на русском

[Community Server](../README.md#mockarty-community-на-русском)

Выберите версию в реестре пакетов для своего языка. В репозитории SDK есть примеры, история выпусков и лицензия. Смотрите лицензию, поставляемую с выбранной версией SDK.

| SDK | Пакет | Репозиторий |
|---|---|---|
| Go | `github.com/mockarty/go-sdk` | [mockarty/go-sdk](https://github.com/mockarty/go-sdk) |
| Python | [`mockarty` на PyPI](https://pypi.org/project/mockarty/) | [mockarty/py-sdk](https://github.com/mockarty/py-sdk) |
| Java | [`ru.mockarty:mockarty-java` в Maven Central](https://central.sonatype.com/artifact/ru.mockarty/mockarty-java) | [mockarty/java-sdk](https://github.com/mockarty/java-sdk) |

Начните с [быстрого старта SDK](https://mockarty.ru/docs/sdk-quick-start?lang=ru). Он показывает подключение к установленному серверу и вызов мока из теста. Используйте токен целевого пространства. Подключённый сервер проверяет роль в пространстве и доступ к модулям.
